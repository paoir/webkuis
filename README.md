# webkuis
Aplikasi kuis sederhana berbasis web php dan database mysql. Tanpa perlu login, user dapat mengikuti kuis dengan mengisi nama dan nomor ujian lalu mengerjakan soal-soal kuis. Setelah kuis selesai peserta dapat melihat nilai. Nilai langsung tersimpan dan dapat dilihat melalui halaman rekap oleh pengelola tanpa fitur login.
